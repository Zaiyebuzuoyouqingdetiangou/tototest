# 1.5.35 稳定性候选范围

基于完整保留的 1.5.34，未改在线酒馆、未调用真实模型、未发布仓库。此包只用于验证，不能把离线通过等同手机实机验收。

## 已实施

- 原外部诊断入口补充安全的传输元数据；同一请求、同一响应流，没有额外 Token。未知字段如实保留未知。
- 减少同节点交互重复初始化。TT 通过公开 ChatSurface v1 的挂载及内容生命周期接入，不在虚化列表根部插入镜面，不关闭虚化。内容刷新与整条消息卸载分别处理，保留仍有效的外置镜面、控件和动画。
- 设置页及弹窗采用 TT 公开布局标记和局部文字样式，不复制第三方美化。
- 多面登记事务中的缩小写入提前，避免最终能放下但中间步骤超额的一类情况。既有过期临时事务回收范围不变，不清历史、不清站点、不动其他扩展；仍失败就停止，不重发 API。
- 高级设置 → 个性化视觉提示词 → 参考外观与交互。默认关闭；粘贴或导入 HTML/TXT 后仅提取有限结构摘要，不执行脚本、不读取外链、不带入原故事文字。需要点击保存并主动打开开关。生成时，关闭状态不读取或发送摘要；用户主动展开该设置时会核对本设备的一份小摘要。

参考摘要存于本设备 IndexedDB。settings 只有开关与版本号，不存 HTML。最多保存当前摘要和仍被设置引用的一份旧摘要，总量有界；丢失关联时可经确认解除旧关联，不删除数据库。安全提取会忽略动画、图片、字体和复杂脚本，因此不是完整复制别人的作品，也不保证模型精确复现。

## 保留的边界

- 不因三标签、版式普通或交互简单拒收安全完整的结果。安全净化、协议闭合、空正文、逐面归属和单次付费请求保护继续有效。
- 内置母本、外部抽签语义、模型参数、美化提示、原成品配色和边框没有重写。
- 真实空间不足、空回、截断、真正不完整的多面仍可能失败；诊断帮助区分原因，不凭空补齐模型未生成的内容。

## 本次未交付

- 破限词编辑与配套母本清理：未修改。
- 跨设备外部母本：官方文件存储可用，但轻量目录缺少并发合并/条件写入能力；不能采用会覆盖另一设备目录的实现。保留 IndexedDB，等待独立服务端方案选择。
- 正文标签闭合提前生成：当前最终事件会改变操作身份，直接接入存在作废早期结果或产生第二次请求资格的风险；保留原触发时机。
- “可见性和过滤后正文为空”的所有宿主组合，以及手机闪烁/回弹的所有原因，尚未完成定位或实机验收。没有为消除错误而把隐藏正文、排除标签重新发给模型。
