# 1.5.25 布局、来源与交互验证

基于保留的 1.5.23。按用户确认的规则撤回统一外框，保留作品自身外观，不修改美化提示。

## 已验证

- 最终整合源码：99 个 Node 测试文件、392 项全部通过，33 个受保护文件与原基线一致（仅版本/cache 标识归一化）。
- 最终生产 JS + CSS：独立/跟随 × 内嵌/外置四条首次挂载路径通过；五面原生勾选、跨层控制、按钮展开/返回、重复折叠、序列化重挂载及来源注释均无需手动维修。此处为原创离线夹具，不是实际用户手机验收。
- 原版在新浏览器回归中复现统一外框覆盖作者边框、长标题工具落在背景之外；自动宽度判断的新增回归在原版失败。
- 修正后：独立/跟随 × 外置/内嵌 × 360/390/844/1280px 共 16 组通过。验证折叠无新增外框、展开保留作者边框和颜色、长文可读、标题工具不越界、自动宽度填充内容层、宽表格可读或可滚动、嵌套展开及隐藏表格开关可逆。
- 自动宽度生命周期：首次展开经原有有限调度纠正窄面；明确的 260px 卡片与 fit-content 意图不被覆盖。
- 来源链：本轮已选条目的数据库读取 → Prompt 元数据 → 精确聊天/消息/Swipe/面号记录 → 本地底部注释。纯外部记录可保留书名，不会因此开放空的内置黑名单菜单；混合五面不串用第一面的书名。书名通过 textContent 显示，伪造 HTML 注释会清除，维修序列化不夹带展示注释。
- 来源名称不改变同一抽取计划生成的 Prompt、随机数消耗及数据库读取次数。1～5 面、来源缺失、同名去重、来源更新、错误 Swipe、正文修订、单面及多面维修元数据均有回归。
- 性能：同一原创五面夹具，Edge 4 倍 CPU 降速，正常 label 点击的 applyCheckedVisualFallback 从每次 4 次降至 1 次；前五次点击的样式读取从 22/26/28/28/28 次降到 12/14/12/14/14 次。时间波动较大，不把该计数或桌面耗时换算成手机提速百分比。30ms 后的模拟状态回退仍修复，快速点击仍以最新操作为准。
- 折叠动画：2 种摆放 × 8 生命周期阶段通过，折叠内容和伪元素暂停，作者主动暂停的动画保持。

## 边界

- 仅生产代码加原创离线夹具，没有读取用户聊天/世界书，没有模型 API 请求。
- 窄面截图没有对应的实际 DOM/样式证据；本次纠正的是确定的 auto-width 漏判与内容层尺寸问题，不保证解决所有固定尺寸、深层定位、缩放或任意宿主 CSS。
- 未增加 Observer、常驻轮询、后台全聊天扫描、动画或网络下载。不能据此宣称手机温升或十几秒延迟已解决。
- 外部小剧场标题按原结果保留，只增加“外部参考：世界书名称”。旧成品没有可信来源元数据时不反推书名，不要求为此重新生成或读取私人母本。
- 手机/电脑跨设备成品与维修结果同步尚未完成。
- 正式与测试包只差通道 manifest，测试开发文件不随安装包分发。
