# 1.5.32 交互返回规则修订

基线为保留的 1.5.31。唯一功能改动文件是 src/promptBuilder.js；其他运行模块仅版本/缓存更新。只更改交互返回约束，不重新设计视觉风格，不改参数、抽取、母本、请求次数、净化、持久化或布局。

共享短规则为：

> 交互返回：可重复交互须能自然切回，优先复用原控件；不强制每个状态另设返回，一次性动作可自然结束。

该句每份 Prompt 一次，适用于跟随/独立、1～5 面、普通/动态/混合批次。去掉核心规则、增强绘制、逐面计划及末尾检查中的一律可逆/逐状态返回要求。完整交互链、明确可保持的状态变化、真实反馈、重复翻面/切换的返回、手机宽度、动画数量及异常维修仍保留。

开发回归通过真实 planner/renderer 固定独立原创选项，覆盖 56 种组合；可用 RABBIT_MIRROR_RETURN_BASELINE 指向旧 promptBuilder.js 比较选项元数据与最终请求字符数。不调用真实生成 API，不冒充真实模型速度或实际作品交互验收。192 组历史 Prompt 基准仍保留，只反转明确授权句子后比较哈希，不能整份重新录制成“通过”。

scripts/release-check.mjs 核验功能变更名单、内置数据、缓存闭包、完整 Node 测试、语法、既有交互/手机离线夹具，以及两包 CRC、新解压后的逐文件哈希与复测。结果写在安装包旁的 verification-result.json；只有 status=PASS 才可交付。

正式与测试安装包的运行代码相同，只区分 manifest 通道字段。不包含开发 tests/scripts/package.json 或用户主题、诊断、聊天、截图和私人母本。未上传仓库或安装线上酒馆；不清理旧文件/用户数据。

边界：规则仅影响之后的生成或用户主动重生成，不自动改写历史成品；尚未测量真实模型生成时间、审美变化、真实手机温升或双向跨设备恢复。本版本不承诺“恢复 30 秒生成”。
