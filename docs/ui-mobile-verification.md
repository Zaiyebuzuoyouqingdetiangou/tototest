# 1.5.23 UI / Mobile 验证记录

基于保留的 1.5.22 公开版。未读取用户的世界书/聊天、未发送模型请求、未修改在线酒馆或仓库。

## 修复及证据

- 抽签显示：原版新增回归首先因缺失“第 1 面”失败。修正后五面短名称、旧版 ID+标题、HTML 转义、缺名称、输入长度上限及不修改记录检查通过；界面最多读取五面、每类十二个既有标签，不读取外部库。
- 设置：真实生产 UI 初始化和事件 + 最小宿主替身共 12 项检查通过，涵盖五面显示、最后两项菜单顺序、导入说明、文件选择、关闭和文字替换保存。
- 边界：原版原创夹具出现五面无边框、内容及卡片越界。修订样式后，独立/跟随 × 内嵌/外置 × 360/390/844/1280px 共 16 组合通过；检查逐面边界、长文最后一行、卡片宽度、宽表格可读、背景颜色保留、嵌套展开返回和隐藏表格开关。
- 动画：两种布局 × 八个生命周期阶段通过，折叠后内容和伪元素暂停，原作者暂停状态保留。
- 导入窗口：18 项真实生产弹窗/移动热修复检查通过；宿主为原创变换及滚动夹具，覆盖嵌套顶层窗口、安全区关闭命中和关闭过程。
- Node 全量：98 个测试文件，390 项通过、0 失败。缓存闭包 343 项检查和 33 个受保护源文件检查通过；母本索引 208 展现、165 主题一致。

## 性能与速度边界

本次运行逻辑修改仅在设置显示与导入说明，布局使用 CSS。未增加模型请求、后台定时器、Observer、整聊天扫描、字体/图片下载；Prompt、美化材料、流式、输出上限和单次请求租约保持。没有通过降低质量或增加并发来提速，也没有承诺服务商生成更快。

现有五面 1045 DOM 节点离线交互基准通过：40 次展开、内部操作、维修菜单、折叠；热路径正文签名重复读取为零，原生交互可逆。一次桌面样本中首轮安装约 190ms，展开派发上限 2ms、内部操作约 7ms、维修菜单约 65ms。这些仅为受控桌面样本，不是 iPhone 的端到端响应时间或性能保证。

## 仍未验收

- 手机发热、功耗和十几秒卡顿必须以真实手机检查；桌面通过不能排除它们。
- 任意模型生成的深层定位、负向 transform、固定画布等布局不保证全部自动修好。宽内容优先可读/可滚动，不盲目缩小全部字体或切掉正文。
- 浏览器夹具使用生产解析和样式，跟随内嵌使用等价结构；不等于完整真实 SillyTavern/服务商/iPhone 验收。
- 成品及维修结果跨设备即时同步尚未完成。

安装包不含开发测试文件；完整测试与截图保存在开发副本。正式/测试包运行文件一致，仅通道标识有差异。用户应在原安装目录更新，整页刷新确认 1.5.23，不要同时启用两份，也不需要清空数据。
