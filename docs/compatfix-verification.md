# 1.5.26 来源与移动兼容修订验证

基线：保留的 1.5.25-sourcefix/source；原目录、旧安装包未覆盖。仅修订本轮来源文案、导入提醒、独立输出契约和导入窗口定位。

## 已确认及修订

- 独立 API 原共享 Prompt 同时含“先完成本轮主回复正文”和独立输出只许镜面的要求，存在契约冲突。新增回归在原代码失败；现按 generationType 分开正文预留及输出顺序。跟随模式保留原文；独立观察已完成正文、不续写正文。未改审美/媒介/选题/动画提示或请求参数。
- 解析器遇到面外文字或注释会报 outside-content。原解析器、安全净化、输出预算、面号与单次请求边界均保持不变；没有用截取任意片段、放宽结构或自动补请求来伪装成功。
- 来源以纯 textContent 显示“本轮抽取来源：书名”；逐面来源沿用可信元数据，不猜书名。底部注释 opacity .72，无底框、遮罩、背景模糊或动画；高对比偏好保留不透明文本。关闭外部抽签以单个根属性立即隐藏已挂载注释，后续装饰不再创建；重新开启按已有元数据恢复。
- 高级设置母本页与导入窗口正文首项均为：“不会进入兔子镜内置，感谢各位制作小剧场的老师，请征求作者同意后使用。”
- 原导入弹窗仅使用布局 vh/dvh 和零偏移。可见视口平移/缩小时新增回归确认关闭按钮落在可见区外；现使用可见视口尺寸与偏移，并移除百分比最大高度的循环尺寸依赖。窗口打开期间绑定 resize/scroll，同帧最多一次，尺寸未变不写样式；关闭释放监听和 RAF。无新增 Observer、轮询、聊天扫描或网络资源。

## 最终离线证据

- 99 个 Node 测试文件、392 项通过。33 个受保护基线文件保持一致（仅版本/cache 归一化）。
- 192 份原始 Prompt 基线仍逐字节校验；只逆向还原本次明确修改的独立输出契约和既有已授权差异，不重新生成 golden hashes。增强美化 OFF/ON、抽签元数据、执行锁和预算检查通过。
- 独立生成 1/2/3/4/5 面 × 普通/固定动态视觉的生产 Prompt 对照通过；二面、三面保留准确数量且不含先写主回复的冲突句。
- 四条生产挂载路径（独立/跟随 × 内嵌/外置）通过来源逐面准确、纯文本防注入、外部开关即刻隐藏、首次交互、重复折叠返回及序列化重挂载检查。
- 生产 JS+CSS 的布局矩阵 16 组通过：4 条路径 × 360/390/844/1280px；原配色/边框保持，自动宽度、长标题和局部滚动未回退。
- 生产导入窗口及 top-layer 热修复通过：变换/滚动宿主、嵌套模态、320/390px、横屏、模拟可见区平移与二次缩小、关闭按钮命中、焦点返回、Escape、读取文件中关闭和监听清理。390px 实际截图已人工查看。
- 五面 1045 节点原创交互夹具，Edge CPU 4 倍降速下首次/重复交互、延迟状态回退与快速切换测试通过；这不是手机基准，不据此推算手机温升或提速百分比。
- 母本索引 check 通过：208 个展现形式、165 个主题；68 个运行时 JS 语法检查通过。
- 正式和测试安装包仅 manifest 的通道名称、仓库主页、自动更新标识不同；不含 tests/scripts/package.json，也不含任何用户导入的世界书。

## 未验收边界

- 用户报告三面自动失败而手动重生成/两面成功，缺少对应响应或内部全链路诊断。本次修复了确定的输出契约冲突，但不能确认这就是该用户所有 outside-content 的原因，更不能承诺所有模型首次生成成功。
- 用户提供的宿主性能报告支持曾出现约 1.6 秒输入排队及长任务；没有可归因脚本，部分为重置前记录；不能据此把耗时归责于某扩展、模型网络或本次修复。
- 所有浏览器测试使用生产代码和原创离线夹具，不含真实模型请求、用户聊天或私人世界书。未在目标安卓本地酒馆/iPhone 完成实机验收，手机温升与长延迟不宣称已解决。
- 成品及维修结果的即时跨设备保存仍未完成。本次交付包不代表已上传仓库或更新在线安装。
