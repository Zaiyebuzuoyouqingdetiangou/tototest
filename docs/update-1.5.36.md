# 1.5.36 使用说明

## 本轮变化

- 拖动回顶与弹幕重启：修复多面被动同步将已有镜面误判为逃逸并反复搬动的问题。正常同步不重建、也不移动已正确排序的镜面；只归位真正错位项。
- 桌面阅读：窗口至少 900px 时，兔子镜单面阅读宽度最多 720px。宿主正文宽度、生成字体与手机布局不变。
- 高级设置的“创作补充规则”：编辑当前启用的默认规则，可保存、清空、恢复默认；上方选择每轮注入／不注入／仅在抽到成人内容时注入。跟随与独立生成都只发送当前文本一份；空文本不会自动补默认。混合多面中的条件模式明确标注适用面号。
- 删除生成器里重复的成人内部执行锁。内置主题与形式原文经过扫描，没有符合这次定义、可单独删除的重复全局执行句；不为凑删除数量削弱具体母本内容。未接入从未启用的旧参考文本，也未新增绕过模型限制的指令。
- 外部库窗口新增“迁移全部外部库（换设备）”：一键导出全部已导入库，目标设备选择迁移文件并确认导入。同编号库整本跳过，保留目标设备现有内容；新库整批事务写入，失败回滚。内容仍在 IndexedDB，不塞进 settings、不在启动时读取整库。
- 外部母本支持 TXT、Markdown 和直接粘贴文字。一个文件／一次粘贴作为一条待分类条目，经过原分类确认流程再保存，不执行其中 HTML，也不请求模型转换。超限整份拒绝，不默默截断；损坏 JSON 不会当纯文本导入。
- 开启已有冷却功能时，同批多面新增主交互路径的分散要求及近期交互家族提示。保持明确点菜／母本原玩法优先；这是生成偏好，不是成品拦截，不能保证模型每面都使用不同交互。

## 可选：正文标签闭合提前生成

独立 API 页中打开“正文标签闭合提前生成”，扫描当前聊天并勾选实际正文标签，或手动输入标签名，然后保存。默认关闭，只绑定当前聊天；最多 8 个标签，所选标签必须全部明确闭合并在当前渲染正文里可见。切换聊天不会继承开启状态或旧候选勾选。

副 API 请求可与主回复尾部并行；结果等主回复确切结束、正文与归属仍一致后再保存展示，避免流式尾部反复刷新镜面。停止、改正文、换 swipe／聊天／相关配置会撤销该早发操作，不自动再发。工具调用可能开启、接口能力未知、正文不可见或结构不确定时，保守使用原来的结束后生成流程。

这不是模型提速开关：主回复尾部很短时收益可能很小，实际收益需要同模型同配置实测。已发出的请求即使后来取消，也可能由服务商计费。

## 长文、迁移与验证边界

已有自然流文本承载可阅读数千字，不会为了适配而截正文；生成内容可以在段落间组织 HTML。固定高度、复杂绝对定位等特定作品仍可能需要单面诊断，不对所有作品强行分页或关闭动画。

普通文本单条上限 100 万字符／文件 8 MiB；迁移包上限 32 MiB、1000 本库、25000 条。跨设备迁移仅包含外部库及其分类／启用状态，不包含 API Key、整个插件配置、聊天或本设备的外观参考。导出的库内可能含私人文本，请自行保管。

本轮不新增后台扫描、网络诊断请求或自动重试。保留既有安全净化、完整性检查、单次请求保护及不以主观版式拒收成品的规则。

离线回归覆盖生产模块、受控宿主事件、Edge 的 DOM／动画／触摸拖动和 IndexedDB。真实手机 Safari、TT 宿主、供应商响应、实际生成速度与交互多样性仍需实机验收。测试包未部署或上传仓库；原版本、聊天与缓存保留。
