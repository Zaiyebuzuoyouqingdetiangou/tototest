# 1.5.38 使用说明

## 补充创作规则

位置：高级设置 → 独立 API，页面最上方。保留注入选择、保存、清空和恢复默认；外围说明精简，框内原文与用户保存内容不变。

## 导入自己的小剧场

设置首页 → 母本库：导入与备份。

- 粘贴文字：填写名称与文字 → 读取文字并进入分类确认 → 选主题（演什么）或展现形式（怎么玩）→ 保存。
- 导入文件：直接选择 TXT、MD、JSON，不必先转换；然后确认分类并保存。每份纯文字默认作为一个条目。
- 保存后在管理母本库启用需要的库，再打开外部母本参与抽签。新库默认停用，不会暗中混入生成。
- 管理母本库中的其他来源页可从酒馆已有世界书导入；源文件和源世界书不修改。

## 换设备

点「换设备：导出／导入整库」：旧设备点一键导出全部外部库，将文件传到新设备，在新设备选择文件并确认导入。保留分类及各库启用状态，同编号旧库跳过不覆盖；抽签总开关不变。不是自动云同步，文件含母本原文，请妥善保管。

## 成品显示

生成、重说与恢复不再调用审美拒收检查。三标签、普通版式、简单交互等不会把已有安全完整成品变成失败卡。美化生成规则、视觉观察与冷却继续保留。

安全净化、实际空正文、协议残缺、归属或容量问题仍会检查；现按真实原因显示，不再一律称为质量检查未通过。模型无法保证每次都生成复杂或美观作品，此次修改不是降低美化要求。

## 更新与验证边界

正式版与测试版只有通道信息不同，请选原来的通道，不要同时启用两份。保留原扩展目录更新后整页刷新，确认 1.5.38，不需要清站点数据、重导库或重置设置。ZIP 交付不表示已上传 GitHub。

本地回归使用原创材料、隔离浏览器及宿主替身，不触发真实模型。真实 iPhone Safari、TauriTavern 与服务商兼容性不由离线测试保证。
