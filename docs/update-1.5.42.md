# 兔子镜小剧场 1.5.42

本次只修复两条 TT 路径，不改变云酒馆的生成和交互逻辑。

## TT 点开后又收起

1.5.41 现场诊断中，5 次触摸均已立即展开，但约 0.3–0.46 秒后的 click 被 WebView 标为 mouse，仍携带同一触摸 pointerId，导致第二次原生 toggle。现在匹配有界的同面、同 pointerId、位置和时间收据，并保留真实鼠标按下的优先权；滑动取消、键盘和内部控件不改。

## TT 虚化后的设置入口

managed 模式的设置入口不再依赖成功收到聊天挂载。它只是一块轻量入口，明确点击后才读取完整设置模块，不在启动时解析母本库。

**设置能打开，不代表虚化聊天已成功接入。** 对截图所示 TT 提交 `223be954afa7b60c8637a44a43319524a185ea11`，普通第三方扩展可能在首次聊天投影后才加载；公开 ChatSurface v1 不支持迟注册。此版不绕过所有权、不关闭虚化，也不靠全历史扫描补挂载。

依据：[对应 TT 的 ChatSurface 文档](https://github.com/Darkatse/TauriTavern/blob/223be954afa7b60c8637a44a43319524a185ea11/docs/API/ChatSurface.md)。

## 本次未改的事项

- 记忆世界书目前只能绑定一本；跟随和独立 API 都仅在抽中共同回忆时读取。
- 复制 HTML 保留原生 HTML/CSS 交互和当前控件状态；不导出兔子镜运行脚本、维修桥接或被隔离的模型脚本。
- “生成失败后翻译替换正文，错误卡变为正在更新”已在生产同步函数的隔离探针复现；尚需翻译插件名称核对实际写入字段。本次仅诊断，不修改生成归属和重试策略，不自动重发请求。

安装只选正式版或测试版一份，不要同时启用。保留原数据后替换插件并重启 TT。

仅源码/自动化验证，尚未真机验证。安装后请只试已有镜面的展开和设置入口，无须额外生成来测试这两个修复。
