# 1.5.30 修复范围与验收边界

基线为保留的 1.5.29。功能修改只有 src/outputSanitizer.js；版本与缓存统一为 1.5.30 / 1.5.30-layout1。

## 修复

1. 标题工具浮动越过标题时，后续 overflow:auto 正文会避让它，产生右侧空白。仅为自己的工具浮动增加空收尾节点；不改正文宽度、配色、原边框和阴影，不覆盖作者的伪元素装饰。Flex/grid 标题不增加此节点占位。
2. 部分全尺寸局部第二层被安全处理成普通排版，位于首屏下方并被裁切。仅在相对定位、有裁切边界、大小在当前镜面内且具备同控件进入/返回标签时恢复局部层定位；不放宽生成代码安全规则。

## 离线检查

- 全量 Node 测试；版本缓存闭包、运行文件语法和内置库索引。
- titleFloatContainment：跟随/独立，单面/五面，375/440/844/1280 宽；工具不挤正文，原边框、阴影、装饰、小卡片尺寸和往返保留。
- localPanelVisibility：跟随/独立，单面/五面；进入、返回、再次操作、不同面隔离、维修回调及重新挂载；无边界、固定定位父层、无返回入口三种情况拒绝补救。
- 既有 frameBoundary、firstUseInteraction、independentInteractionPersistence、passiveAnimationLifecycle、runtimeModalTouch 和指引设置测试。
- ZIP CRC、新目录解压、逐文件 SHA-256 对比；从最终包解压的代码重新运行测试。

测试使用原创内容和本地 Edge 触摸模拟，不发送模型请求。用户提供的诊断仅本地私下复现，不进入分发包或公共测试。
