# 1.5.31 修复边界与验证方法

基线为 1.5.30（已保留 1.5.29 修复）。只处理本轮三类问题，不重写美化提示、母本、抽取计划或 API 协议。

| 要求/风险 | 可观察行为 | 离线证据 |
| --- | --- | --- |
| 本地满额 | 仅在多面登记的 QuotaExceededError 后，同一计划最多重试一次本地事务 | quotaTemporaryRecovery.test.mjs：一次失败恢复、持续满额、实际字节上限、最后一项写入失败回滚 |
| 保护旧数据 | 不修改历史/成品/维修/其他插件、未知结构或有效异页临时记录 | 白名单与保护哨兵、异常时间、外部写入冲突用例 |
| 不重复收费 | 不重抽计划、不追加网络请求；恢复成功只有一份登记/每面一条尝试 | 公开登记入口、已有 multifaceDispatchRegistration 和网络次数回归 |
| CSS 代码露出 | 完整独立的 keyframes 从可见文字恢复到安全样式；正文示例/残缺代码不猜测 | temporaryQuotaUi.browser.mjs：原创建例、5 面动画命名隔离、原生点击/返回、安全资源过滤 |
| 底部遮字 | 独立外置镜面前只保留正文页脚实际伸出距离 + 6px | 360/390/844/1280px 布局；50px 页脚得到 56px margin，无页脚仍 0px |
| 手机额外负担 | 不新增计时器/轮询，不遍历聊天历史；几何不变不写 DOM | 浏览器连续 20 次调度：0 次 DOM 修改；原有交互/动画/宽度/帮助导航回归 |

私下对用户提供的诊断源码和主题做了本地检查：诊断中的裸露 keyframes 恢复后不可见，4 个原控制仍保留；主题的页脚 bottom=-50px，适配 margin 为 56px。远程图片/字体请求全部阻断，未调用模型。主题、聊天、诊断、截图不进入本包或公开测试数据。

临时回收只访问四个固定键：pending_combo:v11、pending_batch:v1、pending_batch_registry:v2、generation_attempts:v1（均使用 rabbit_mirror_theater 前缀）。仅确认过期超过 12 小时的记录可回收；不凭会话不同判断失效。超过检查预算或结构无法确认时保留。清理失败、空间仍不足或可检测的其他标签页写入冲突时停止。localStorage 没有原子跨标签比较交换，不能把此回收当作跨设备同步协议。

运行验证使用现有 Node 测试、语法/内置索引检查和离线 Edge 触摸布局夹具。scripts/release-check.mjs 记录源目录与正式 ZIP 新解压目录的全量测试、CRC、文件清单与 SHA256；最终结果保存在安装包旁的 verification-result.json。未通过完整发布检查不交付。

未验收：真实手机的发热和长时性能、所有第三方美化、真实模型新输出，以及手机到电脑/电脑到手机的双向成品和维修结果恢复。本版本不宣称这些全部修复。不需要为此清站点、删除旧数据或反复生成。
