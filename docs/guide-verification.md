# 1.5.38 指引范围与验收说明

本次同步：保留默认折叠、首次打开才加载、两种入门流程、六类目录与返回定位。基础配置仍为跟随 4 步、独立 6 步；新增纯文字／文件／整库搬家的可选快捷说明，不把这些操作变为必需步骤。

- 主设置的“母本库：导入与备份”提供粘贴文字、TXT / MD / JSON 文件与整库导出／导入入口；指引只定位这些按钮，不自动打开选择器、读取或保存内容。
- 新库流程说明为：填名称及文字／选择文件 → 确认主题（演什么）或展现形式（怎么玩） → 保存 → 启用库 → 打开外部母本参与抽签。默认停用状态不变。
- 换设备流程说明为：旧设备导出 → 传文件 → 新设备导入 → 核对确认。同编号已有库跳过、不覆盖，不替用户更改抽签总开关，也不是自动云同步。
- 补充创作规则与正文标签闭合提前生成定位到“高级设置 → 独立 API”。阅读指引不会修改这些设置，也不自动展开可能读取已保存外观参考的入口。

新增静态契约覆盖以上 6 个真实选择器及页面位置、文字导入分类和启用说明、整库确认步骤、可选入口无需展开完整目录、旧基础步骤数量和无设置写入／API／自动按钮执行边界。实际 UI 整合与移动宽度仍须运行 `tests/usabilityExternalAdvanced.browser.mjs`，不能仅以静态契约证明浏览器通过。
