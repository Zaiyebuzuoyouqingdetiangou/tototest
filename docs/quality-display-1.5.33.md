# 1.5.33：成品优先展示

基线：保留的 1.5.32。仅两处运行模块有功能变化：

- `independentQualityGate.js`：三标签、单揭示、低对比和缺牌图只返回审美观察，不再拒绝。
- `independentApi.js`：取消视觉 CSS 缺失、去标题后正文重复的拒绝；旧失败卡有有效预览缓存时，一次点击直接展开最外作品，不打开内层交互或邻面。

共享审美观察用于独立单面/多面、跟随多面、失败面手动重试与历史恢复。扫描器原有风险记录和下一轮避免套模板的机制保留。不新增 Prompt，也不改 1.5.32 的自然返回规则。

## 仍然保留的边界

安全净化、外链白名单、脚本移除、空正文、真实协议/闭合错误、逐面身份、体积/节点预算和一次请求保护不变。出现危险片段仍先净化；能留下安全内容就展示，不能留下可用正文或结构/归属不可信则仍停止。不会为展示效果自动重发 API。

## 旧内容

预览缓存是原有的有界内存缓存，不是永久存档。只有缓存尚存在时，预览按钮才有内容可显示。升级/刷新不能找回旧版没有保存、且缓存已经失效的原始结果。本版不删除历史、母本或站点数据。

## 验证说明

回归使用原创离线数据：三标签五面不再变失败卡、正文重复/CSS 不足保留、空内容仍失败、单次请求次数、历史恢复和旧预览的外层展开/内部与邻面状态隔离。

生产源码和新鲜解压包分别验证。开发目录外的 `verification-result.json` 记录发布脚本最终状态、测试数量和 ZIP SHA-256；只有 PASS 才可交付。测试/脚本不进入运行 ZIP。

本次不调用真实模型、不上传仓库。真实 Android/iOS、具体用户主题、模型输出审美与耗时没有由离线测试代验收；双向跨设备保存仍未完成。
