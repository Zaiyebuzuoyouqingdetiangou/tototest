# 1.5.27 移动适配与小型工具入口

基线为用户提供的正式 1.5.26（content-title1）。未向真实模型发送请求，未发布仓库，也未改第三方美化文件。

## 修改边界

- `composerClearance.js`：重叠量计算、按需留空、合并布局测量；不读取正文，不扫描母本，不轮询，不改原主题样式。只监听聊天直接子节点、相关尺寸和可见视口变化；禁用时撤销。
- `independentApi.js` / `outputSanitizer.js`：忽略 RabbitMirror 内部结构修改引起的恢复事件；保留真正宿主消息删除、重建、切换的入口。
- `extensionUpdater.js`：用户点击后，确认执行模块所属安装目录，再通过宿主 discovery/update 接口更新该目录；权限和 Git 操作由宿主控制，不猜其他仓库、不重装、不自动重试。
- `ui.js` / `style.css`：原界面内增加折叠四步指引与更新状态；44px 点击目标；不改生成美化规则及镜面边框。
- `index.js`：适配服务跟随现有延迟初始化及禁用清理；统一 1.5.27-mobile1 模块缓存键。

## 已执行的针对性检查

- 新增 Node 测试：更新目标、双击合并、本地/全局安装、权限失败、无自动重装及几何边界。
- 浏览器原创夹具：375×812、390×844、844×390；分别使用默认 CSS 及用户提供的两套美化 CSS（远程字体/图片全部阻断，不打包主题）。到底后标题位于底栏之上。
- 布局不变时连续调度 20 次，无额外 DOM 写入；禁用移除自身留空；内部节点变动不触发恢复，真实消息移除仍识别原消息。
- 生产设置 UI 的初始化和点击处理连接模拟宿主更新接口，确认只发送当前扩展目录、成功显示手动刷新按钮。
- 新手指引默认折叠高度 44px，点击展开四步文字；没有默认遮罩或强制弹出。

全量测试、语法、打包及重新解压逐字节校验由附带 release-check.mjs 执行，最终结果保留在安装包外的 verification-result.json；不能将仅存在测试文件视为测试通过。

## 仍需实机确认

没有连接用户的安卓本机、iPhone Safari 或真实宿主更新接口。模拟浏览器不等于实机；视频抽帧也不能证明所有快速闪烁已复现。需要检查原视频场景连续折叠/展开、浏览器工具栏/软键盘变化、切换聊天后恢复、设备温度及流畅性。

此版本不宣称全面解决手机发热、所有主题遮挡或所有安卓闪烁。更新按钮不能绕过服务器权限，不能使不支持更新接口/非 Git 的安装自动变得可更新。跨设备保存行为不在本轮修改范围内。
