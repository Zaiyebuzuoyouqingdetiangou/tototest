# 1.5.37 更新

## 外部库导入

一键导出的 `RabbitMirror-external-libraries-日期.json` 可以直接从普通“从本地文件导入”入口选择；按文件内容识别，不依赖文件名。校验后展开迁移确认，确认前不写入。专用迁移入口仍保留。同编号库跳过，不覆盖已有内容；备份里的分类和启用状态保留，外部抽签总开关不自动改变。

普通 JSON、TXT、MD 和粘贴文字仍可导入。新库须分类、保存并启用，还需要打开“外部母本参与抽签”。不把整库塞进 settings，也不会在启动时读取整库正文。测试验证到抽中 ID 的原文读取，不代表模型一定逐字采用条目或实际生成审美已验收。

## 补充创作规则

编辑器移到“独立 API”分区上方，直接显示，不再藏在视觉规则折叠里。感谢 @lannuomi；两段原文、原始注释与导出声明完整作为普通文本保留，并提供编辑、清空、关闭、恢复默认。

只影响独立 API，不向跟随正文注入这一块。请求只包含当前保存的一份文本，不叠加另一份隐藏默认词，不执行文本中的代码。每轮／不注入／仅抽到成人条目时注入三种选择保留。已有手动编辑、清空和关闭状态不会被升级覆盖；需要完整版可点“恢复默认”，该按钮不改变注入方式。

完整默认内容比旧版更长，会增加输入 Token，仍计入原请求预算。原文件中的“NOT injected”属于保留的历史注释，现版本以编辑器的选择与保存内容为准。

## 提前生成与诊断

保留正文标签闭合时立即生成、主流与副流独立取消以及一次请求原则。可确认使用不同 Profile、但副连接缺少独立凭据引用或有效独立代理时，在发送前给出绑定提示，不借用当前正文的活动密钥。需要用户在 Connection Manager 完成真实绑定；插件不读取或复制密钥。

泛称 `API request failed` 不再被当作“Secret 没保存”的证据。认证、限流、并发和未知原因分别记录；最近最多 12 条会话传输摘要允许失败后再打开外部诊断查看。不增加模型请求，不保存正文、Prompt、密钥或聊天身份，刷新及主动清空会移除。

详见 [连接与诊断边界](early-connection-transport-1.5.37.md)。用户旧报告没有那次请求的实际 HTTP 和响应信息，因此无法认定其唯一故障原因；这些修复不能代替服务商真实认证与并发能力验收。

## 安装与验证边界

正式版名称为“兔子镜小剧场”，测试版为“兔子镜小剧场测试版”。两个包运行代码一致，仅 manifest 通道字段不同。更新原目录并整页刷新，不同时启用两份；不需要清空缓存或重导已有库。覆盖 ZIP 不会自动切换安装目录的 Git 远程仓库。

交付 ZIP 不等于已上传仓库。回归使用本地原创建库、真实浏览器 DOM / IndexedDB 和受控宿主接口，没有请求用户云酒馆、真实模型或操作用户库。手机 Safari、真实 TT 和服务商鉴权仍需目标环境确认。
