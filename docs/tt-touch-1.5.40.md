# 1.5.40 TT 标题触摸修复（正式通道）

基线是用户上传的 `RabbitMirror-1.5.39-TT-touchfix-test-full(1).zip`。本次未安装到实际酒馆，未访问用户聊天或 API，未提交或发布到远程仓库。

正式版运行代码与已交付的 1.5.40 TT 修复测试包逐字节一致，仅 manifest 的显示名称、主页、自动更新标记和本说明/README 有差异。没有实现随后讨论的手动生成功能，也没有借转正式版修改其他功能。

## 修复范围

- 仅非 managed TT 的外层兔子镜标题，touch/pen 轻点后快速展开或收起。
- 按触摸指针及位置保留迟到 click 的配对记录，避免连续点按挤掉前几次记录、迟到 click 又把刚展开的镜面关闭。
- 鼠标和键盘不会消耗触摸的配对记录；旧 WebView 缺少指针编号时使用有限的位置与来源匹配。
- 拖动超过阈值后，即使滑回起点也不当轻点；取消、重叠指针、非主指针及右键不快速切换。卸载时清理监听和暂存记录。
- 原有 TT 诊断按时间顺序显示输入、快速展开、迟到 click 抑制及匹配依据；明确捕获阶段的 open 值可能早于浏览器默认动作。

暂存记录有数量和时间上限，达到上限时不再接管新的快速切换，交还原生点击。没有新增常驻轮询、Observer、启动整库扫描或诊断布局测量。

## 未改变

云酒馆、managed TT、鼠标和键盘仍走原路径。生成、独立 API 请求次数和失败不重试、Prompt、美化 CSS、维修兔、挨打猫、Touch Theater、多面及外部母本库不在本次修改范围。除了同步版本与缓存引用，实质运行代码差异只有 `outputSanitizer.js`、`ttSurfaceDiagnostics.js` 和 UI 的诊断标量采集。

- 邻近浏览器回归通过：五面内容展开/收起、内部控件、维修菜单、源签名缓存隔离及文本裁切安全边界。该场景不模拟 TT，不等于云酒馆或手机实测。

## 使用与边界

本次交付 `RabbitMirror-1.5.40.zip`，显示名称统一为“兔子镜小剧场”，正式仓库主页为 `https://github.com/Zaiyebuzuoyouqingdetiangou/toto`，自动更新标记开启。安装包不含 tests/scripts/package.json；开发文件与此前测试 ZIP 单独保留。

备份原插件文件后，把 ZIP 中 `RabbitMirror` 目录内的内容覆盖到原扩展目录，保持原目录名称，不要嵌套第二层或同时启用两份。整页刷新，确认 1.5.40。无需清缓存、重导母本、重做聊天或重新付费生成：直接点按、连续展开收起和滚动已有镜面即可检查。

覆盖 ZIP 只更新文件，不会切换原安装目录的 Git 远程。若原先安装测试仓库，自动或手动更新仍可能取原测试仓库版本。本次没有发布远程版本，也没有修改任何实际安装。

**仅源码与离线自动化验证，尚未 TT 真机验证。** 这修复的是已复现的触摸配对和误切换，不证明已消除 TT 宿主约 1 秒 click 延迟的根本原因，也不代表所有滚动、动画或其他卡顿都已解决。旧 WebView 完全不提供点击来源时仍有信息限制；若真机还有问题，可用已有 TT 诊断记录，不必新生成。
